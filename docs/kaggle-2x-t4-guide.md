# Руководство по запуску YuE2 Studio на Kaggle (2x Tesla T4 GPU)

YuE2 Studio поддерживает полнофункциональный облачный бэкенд на **Kaggle** с использованием двух видеокарт **2x Tesla T4 (суммарно 32 ГБ VRAM)**.

---

## ⚡ Ключевые возможности облачного сервера

- **Бесплатно 30 часов GPU в неделю** от Kaggle.
- **Параллельная генерация (Dual-GPU)**: GPU 0 и GPU 1 синтезируют аудио одновременно — за один прогон вы получаете сразу **2 разных варианта трека** с разными сидами.
- **Интеллектуальное автоотключение (Auto-Idle 10 мин)**: если вы не отправляете задачи в течение 10 минут, сервер автоматически останавливается, экономя вашу недельную квоту GPU.
- **Живой мониторинг и логи в реальном времени**: встроенный эндпоинт `/logs` передает прямо на экран телефона или ПК консольные логи, использование VRAM, шаги Flow-Matching и таймер простоя.
- **Мгновенный старт за 0 секунд**: сервер подтягивает предкомпилированный бинарник `yue-server` и квантованные модели Q8_0 из датасета Kaggle без повторного скачивания.

---

## 🔑 Шаг 0: Подготовка аккаунта Kaggle (выполняется один раз)

1. **Регистрация**:
   - Перейдите на [kaggle.com](https://www.kaggle.com) и зарегистрируйтесь / войдите в аккаунт.
2. **Верификация номера телефона (обязательно)**:
   - Перейдите в [Настройки профиля Kaggle (Account Settings)](https://www.kaggle.com/settings).
   - В разделе **Phone Verification** привяжите номер телефона по SMS.
   - *Это бесплатно и активирует доступ к GPU и интернету в виртуальных контейнерах.*
3. **Получение API токена**:
   - В настройках аккаунта найдите раздел **API** и нажмите **`Create New Token`**.
   - Браузер скачает файл `kaggle.json`. Внутри находятся две строки:
     ```json
     {"username":"ВАШ_ЛОГИН","key":"ВАШ_API_КЛЮЧ"}
     ```
4. **Создание датасета моделей на Kaggle (для старта за 0 секунд)**:
   - На ПК запустите файл `create-yue2-dataset.bat`.
   - Скрипт создаст в вашем аккаунте приватный датасет `yue2-q8-models` со скомпилированным движком и весами моделей.

## 📱 Способ 1: Запуск из мобильного приложения Android (в 1 клик)

Самый быстрый и удобный способ — управление сервером прямо с экрана смартфона:

1. Откройте приложение **YuE2 Studio** на телефоне.
2. Перейдите на нижнюю вкладку **«Сервер»**.
3. В блоке **Учетные данные Kaggle API** введите ваш `Username` и `API Key` (из файла `kaggle.json`) и нажмите **«Сохранить»**.
4. Нажмите кнопку **«🚀 Включить сервер Kaggle (2x Tesla T4)»**.
5. Что происходит автоматически:
   - Приложение отправляет задачу запуска виртуального ядра на Kaggle.
   - Как только контейнер поднимается и создает защищенный Cloudflare-туннель, верхний статус загорится зеленым: **`Сервер: On (2x Tesla T4)`**.
   - Никаких ссылок вручную копировать не требуется — приложение подключается само.
6. **Мониторинг**: нажмите кнопку **«📋 Логи и мониторинг сервера Kaggle»**, чтобы в реальном времени наблюдать прогресс загрузки, инициализацию двух видеокарт и таймер автоотключения.
7. **Остановка**: нажмите **«🛑 Выключить сервер Kaggle»** или просто закройте приложение — через 10 минут простоя сервер сам выключится и сохранит ваши часы.

## 💻 Способ 2: Запуск с компьютера Windows (`launch-kaggle.bat`)

Для работы на ПК без открытия браузера:

1. Скопируйте файл `kaggle.json` в папку `C:\Users\<Ваш_Пользователь>\.kaggle\kaggle.json` (или положите рядом в корень проекта).
2. Дважды кликните по файлу:
   ```text
   launch-kaggle.bat
   ```
3. Скрипт:
   - Отправит headless-ядро в Kaggle с ускорителем 2x Tesla T4.
   - Дождется поднятия защищенного туннеля.
   - Настроит локальный мост `127.0.0.1:18087` и автоматически запустит интерфейс **YuE2 Studio**.
4. Для остановки сервера запустите `stop-kaggle.bat` или нажмите `Ctrl+C` в окне консоли.

## 🌐 Способ 3: Ручной запуск через веб-блокнот Kaggle (Interactive Notebook)

Если вы хотите работать интерактивно через браузер:

1. На [kaggle.com](https://www.kaggle.com) нажмите **`+ Create` ➔ `New Notebook`**.
2. В верхнем меню выберите **`File` ➔ `Import Notebook`** ➔ загрузите файл:
   ```text
   kaggle/YuE2_Studio_Kaggle_2xT4.ipynb
   ```
3. В правой панели настроек блокнота (**Notebook options**):
   - **Accelerator**: выберите **`GPU T4 x 2`**.
   - **Internet**: переведите в **`Internet On`**.
4. Нажмите **`+ Add Input`** и прикрепите ваш датасет `yue2-q8-models`.
5. Нажмите **`Run All`** (или выполните ячейки по порядку).
6. В выводе финальной ячейки появится публичный URL вида:
   ```text
   https://xxxx-xxxx-xxxx.trycloudflare.com
   ```
7. Вставьте эту ссылку в настольное приложение или в `connect-kaggle.bat`.

## 🛠 Устранение неполадок

| Проблема | Причина | Решение |
|---|---|---|
| Ошибка `403 Forbidden` или `Internet is disabled` | В аккаунте Kaggle не включен интернет | Привяжите номер телефона в настройках профиля Kaggle |
| Сервер долго запускается (>3 минут) | Очередь на GPU в Kaggle | Подождите 1-2 минуты, Kaggle выделит 2x Tesla T4 |
| Логи были пусты в окне мониторинга | Kaggle буферизует stdout до конца сессии | Обновленная версия приложения использует прямой эндпоинт `/logs` сервера |
| Закончилась квота GPU | Исчерпан лимит 30 часов в неделю | Квота автоматически сбрасывается каждый понедельник в 03:00 МСК |
