# Руководство по запуску YuE2 Studio на Kaggle (2x Tesla T4)

Этот гайд поможет вам запустить облачный движок YuE2 Studio на бесплатном сервисе **Kaggle** с использованием связки из **двух видеокарт Tesla T4 (2x 16 GB = 32 GB VRAM)**.

---

## ⚡ Преимущества Kaggle по сравнению с Google Colab

| Характеристика | Google Colab (Free) | Kaggle (Free) |
|---|---|---|
| **Лимит времени** | ~3–4 часа в день (быстро заканчивается) | **30 часов в неделю** (сброс каждую неделю) |
| **Количество GPU** | 1x Tesla T4 (15 GB VRAM) | **2x Tesla T4 (32 GB VRAM суммарно)** |
| **Память для моделей** | Приходится делить VRAM между музыкой и MIDI | **GPU 0 — YuE2 Q8/BF16, GPU 1 — MuScriptor Large** |
| **Вылеты Out of Memory** | Возможны при одновременной генерации | **Исключены (каждая модель на своей видеокарте)** |
| **Скорость скачивания** | ~50–70 МБ/с | **До 150 МБ/с (модели загружаются за 30 секунд)** |

---

## 🚀 Пошаговая инструкция по запуску

### Шаг 1. Создание блокнота на Kaggle
1. Перейдите на сайт [kaggle.com](https://www.kaggle.com) и войдите в свой аккаунт (или зарегистрируйтесь).
2. В верхнем левом углу нажмите кнопку **`+ Create`** ➔ **`New Notebook`**.

---

### Шаг 2. Загрузка файла блокнота
1. В открывшемся блокноте откройте верхнее меню: **`File` ➔ `Import Notebook`**.
2. Перейдите на вкладку **Upload Notebook**.
3. Выберите файл с вашего компьютера:
   `c:\Project\YuE2_Studio\kaggle\YuE2_Studio_Kaggle_2xT4.ipynb`
4. Нажмите **Import**.

---

### Шаг 3. ВАЖНО: Настройка ускорителя и интернета
В правой боковой панели блокнота Kaggle найдите раздел **Settings / Notebook options**:
1. **Accelerator:** нажмите и переключите на **`GPU T4 x 2`** *(именно два T4, а не один)*.
2. **Internet:** переведите тумблер в положение **`Internet On`**.
   *(Если аккаунт Kaggle новый, Kaggle попросит один раз привязать номер телефона через SMS — это бесплатно и активирует доступ в интернет)*.

---

### Шаг 3.5 (Опционально). Использование файлов с Google Диска и очистка диска
В отличие от Colab, в Kaggle строгий лимит диска `/kaggle/working` — **19.5 ГБ**.

1. **Ничего не настраивать (рекомендуется):** Интернет в Kaggle очень быстрый — при запуске Шага 2 модели скачаются напрямую из Hugging Face за ~30 секунд.
2. **Если диск переполнился (`Errno 28 No space left on device`):**
   * Запустите ячейку **Шаг 1.4 (🧹 Очистка диска и проверка готовых моделей)**.
   * Она в один клик удалит тяжёлую недокачанную папку `models_bf16` (~9-10 ГБ), очистит кэши и освободит ~10 ГБ диска.
3. **Умное скачивание с Google Диска (Шаг 1.5):**
   * Вставьте ссылку на папку или отдельный файл в **Шаг 1.5**.
   * Выберите режим `Q8_0 (Рекомендуется)` — блокнот автоматически пропустит тяжёлые файлы BF16 и скачает только нужные модели (~4.5 ГБ), не забивая диск!
4. **Kaggle Datasets (мгновенно, 0 секунд ожидания):**
   * Создайте приватный датасет на Kaggle с вашими моделями, нажмите справа **`+ Add Input`** ➔ прикрепите датасет, и сервер мгновенно подхватит модели без скачивания (датасеты не занимают место на рабочем диске).

---

### Шаг 4. Запуск сервера
1. Запустите **Шаг 1 (Check GPU)**:
   * Вы увидите отчет о двух найденных видеокартах: `GPU 0: Tesla T4 (15.0 GB)` и `GPU 1: Tesla T4 (15.0 GB)`.
2. Запустите **Шаг 2 (Configure & Launch Server)**:
   * Сервер автоматически скомпилирует `yue2.cpp` под архитектуру Turing, скачает модели на сверхскорости Kaggle и запустит туннель Cloudflare.
3. В выводе ячейки появится красивая синяя плашка с ссылкой вида:
   ```text
   https://xxxx-xxxx-xxxx.trycloudflare.com
   ```

---

### Шаг 5. Подключение программы на ПК
1. На вашем компьютере запустите файл:
   `connect-colab.bat`
2. Вставьте скопированную ссылку из Kaggle и нажмите **Enter**.
3. Готово! Теперь и генерация музыки в Q8_0/BF16, и транскрибация Аудио в MIDI через волшебную палочку работают одновременно на двух мощных GPU Tesla T4.
