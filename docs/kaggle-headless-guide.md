# 🚀 YuE2 Studio — Безбраузерный запуск на Kaggle (2x Tesla T4)

Этот режим позволяет запускать облачный сервер **YuE2 Studio** на связке из **двух видеокарт Tesla T4 (32 ГБ VRAM)** в один клик с рабочего стола Windows — **без открытия браузера и без ручного копирования ссылок**.

---

## ⚡ Как это работает

```text
[ launch-kaggle.bat на ПК ] 
         │ (Kaggle API)
         ▼
[ Сервер Kaggle в облаке ] ➔ Поднимает 2x Tesla T4 и модели из вашего датасета
         │ (Cloudflare Tunnel)
         ▼
[ Мгновенный сигнал ntfy.sh ] ➔ Передаёт приватную ссылку на ваш ПК за 0.1 сек
         │
         ▼
[ Локальный мост 127.0.0.1:18087 ] ➔ Автоматически открывает YuE2 Studio на ПК!
```

---

## 🎯 Запуск в 1 клик

В корневой папке проекта дважды кликните по файлу:
```text
launch-kaggle.bat
```

Что произойдёт автоматически:
1. **[1/3]** Скрипт отправит задачу в облако Kaggle с флагом GPU (2x Tesla T4) и подключит ваш личный датасет `yue2-q8-models`.
2. **[2/3]** Дождётся старта туннеля (обычно 30–60 секунд).
3. **[3/3]** Получит ссылку через канал `ntfy.sh`, активирует локальный мост и **автоматически откроет приложение YuE2 Studio**.

---

## 💡 Преимущества перед браузером

| Параметр | Через браузер (интерактивно) | Безбраузерный запуск (`launch-kaggle.bat`) |
|---|---|---|
| **Действия пользователя** | Открыть браузер ➔ открыть блокнот ➔ нажать Run ➔ скопировать ссылку ➔ вставить в bat | **1 клик по `launch-kaggle.bat`** |
| **Время работы сессии** | Засыпает через 20 минут бездействия | **Работает до 12 часов непрерывно** |
| **Нагрузка на ПК** | Браузер потребляет оперативную память | **Браузер не нужен вообще** |
| **Стабильность** | При случайном закрытии вкладки сессия может прерваться | Сервер надёжно крутится в облаке Kaggle |

---

## 🛑 Как остановить сервер

Чтобы остановить мост и завершить сессию, просто нажмите **`Ctrl + C`** в чёрном окне консоли `launch-kaggle.bat`.
